# supsad.github.io

The root of https://supsad.github.io/. It sends visitors to the
[LumiCells](https://github.com/supsad/lumicells) demo at https://supsad.github.io/lumicells/ and
holds the files search engines read only from the root of a site: `robots.txt` with the sitemap
of the demo and the Yandex Webmaster verification file.

Project sites such as `/lumicells/` are published from their own repositories.
